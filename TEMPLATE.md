# Pavel Erokhin

Senior software engineer and architect in Madrid, specializing in AI agents, Android, and backend development. In AI, I work on agent reliability: OpenTelemetry tracing, LLM evals, tests for context and agent harnesses, guardrails, and running all of these processes in CI, as in my projects Allay and ctxray.

In engineering since 2017. I’ve worked on high-load mobile and backend systems at Wildberries (100M+ MAU), Guava Pay, Alfa-Bank, and MTS Bank, designing and shipping features from architecture to release. In fintech I built the features the product lives on: payments, subscriptions, transfers (SBP, EFT, Interac, FPS, SWIFT), support chat, transaction history, financial wellbeing, and a payment SDK for clients. Beyond payments, I shipped OCR for receipts, documents, and phone numbers, biometric KYC on ML Kit, and CI/CD pipelines.

Deep knowledge of the JVM and the JDK (JIT, GC, JMM, JFR). Extensive expertise in conducting technical interviews for big tech, with 200+ technical interviews conducted.
