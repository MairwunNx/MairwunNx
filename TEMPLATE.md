# Pavel Erokhin

Senior software engineer and architect in Madrid, specializing in AI agents, Android, and backend development. In AI, I work on the tooling around agents: harnesses, MCP servers, and LLM evaluation. I care about agents that hold up in production the way big-tech systems do: OpenTelemetry tracing, LLM evals, context tests in CI, and tightly scoped tool permissions.

In engineering since 2017. I’ve worked on high-load mobile and backend systems at Wildberries (100M+ MAU), Guava Pay, Alfa-Bank, and MTS Bank, designing and shipping features from architecture to release.
